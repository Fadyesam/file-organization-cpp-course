# File Organization with C++

> مادة تطبيقية لتعلّم التعامل مع الملفات في لغة C++، من القراءة والكتابة الأساسية إلى مؤشرات الملفات وعمليات الحذف والترتيب.

## محتوى الكورس

| السكشن | الموضوعات | أبرز الملفات |
|---|---|---|
| 1 | `getline`، المصفوفات النصية، فتح الملف والكتابة فيه | `01_cin_vs_getline.cpp` إلى `06_task1_student_file.cpp` |
| 2 | مشكلة `cin` مع `getline`، القراءة والكتابة، و`ios::trunc` | `01_getline_problem.cpp` إلى `07_task2_fruits.cpp` |
| 3 | مؤشرا القراءة والكتابة: `tellg` / `seekg` / `tellp` / `seekp` | `src/` و`data/` |
| 4 | `struct` و`vector` وحفظ بيانات الأشخاص واسترجاعها | ملفات السكشن ومجلد `task/` |
| 5 | أنماط فتح الملفات: `out` و`app` و`ate` وسجلات الطلاب | `00_create_sample_files.cpp` إلى `06_read_students_records.cpp` |
| 6 | حالة الـ stream، نهاية الملف، وحذف قيمة أو سطر | `01_check_open_fail.cpp` إلى `05_delete_line.cpp` |
| 7 | عدّ المحارف وترتيب الأرقام المقروءة من ملف | `example1_count_chars.cpp` إلى `example3_sort_descending.cpp` |

## المتطلبات

- مترجم C++ يدعم C++17 أو أحدث، مثل **GCC / MinGW-w64** أو **MSVC**.
- Visual Studio Code اختياري، مع إضافة **C/C++** من Microsoft.

تحقق من وجود المترجم:

```powershell
g++ --version
```

## طريقة التشغيل

1. افتح مجلد الكورس في VS Code أو في PowerShell.
2. انتقل إلى المجلد الذي يحوي المثال الذي تريد تشغيله.
3. ترجم الملف ثم شغّله. مثال من السكشن الأول:

```powershell
cd sec_1
g++ -std=c++17 05_write_to_file.cpp -o write_to_file
.\write_to_file.exe
```

> معظم الأمثلة تستخدم مسارات نسبية لملفات البيانات؛ شغّلها من داخل مجلد السكشن. في السكشن 3 شغّلها من `sec_3/src` حتى يجد البرنامج مجلد `../data`.

### أمثلة تحتاج إعدادًا مسبقًا

- **السكشن 2:** الأمثلة `05` و`06` تقرأ `file.txt` الموجود في المجلد نفسه.
- **السكشن 3:** لا تحذف مجلد `data`؛ فهو يحتوي ملفات الإدخال للأمثلة.
- **السكشن 5:** شغّل `00_create_sample_files.cpp` مرة أولى قبل الأمثلة `02` إلى `04`.
- **السكشن 5:** شغّل `05_task5_students_records.cpp` قبل `06_read_students_records.cpp`.
- **السكشن 6:** الأمثلة `04` و`05` تعدّل ملفات داخل `data/`. أعد نسخ الملفات الأصلية إن أردت إعادة التجربة.
- **السكشن 7:** شغّل الأمثلة من داخل `sec_7` حتى يجد البرنامج `info.txt` و`numbers.txt`.

## التمارين

- `sec_1/06_task1_student_file.cpp`: إدخال بيانات طالب وحفظها في ملف.
- `sec_2/07_task2_fruits.cpp`: استكمال إضافة البيانات إلى ملف الفواكه.
- `sec_3/src/11_task3_solution.cpp`: تدريب على الاستبدال باستخدام موضع الكتابة.
- `sec_4/task/`: حفظ الأشخاص ثم إيجاد الأصغر والأكبر عمرًا.
- `sec_5/05_task5_students_records.cpp`: حفظ سجلات طلاب باستخدام الفاصل `$`.

## ملاحظات للطلاب

- استخدم `getline` عند قراءة نص قد يحتوي مسافات.
- بعد `cin >>` وقبل `getline` استخدم `cin.ignore(...)` لإزالة محرف Enter المتبقي.
- تحقق دائمًا من فتح الملف قبل القراءة أو الكتابة.
- جرّب على نسخة من ملفات البيانات عند استخدام أمثلة الحذف أو الاستبدال.
